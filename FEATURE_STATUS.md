exact live gate. Release 0.6B adds the operational editorial and published-content
paths above. Local verification passed 135 unit/integration tests, six Studio
browser cases, eight original server-backed browser cases, 14 original production
browser-demo cases and both production build modes. See [TESTING.md](TESTING.md)
for executed evidence and provider exclusions.
Releases 0.6C (Instructor) and 0.6D (retention) remain subsequent work.
